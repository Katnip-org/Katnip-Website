# Katnip Website

The in-browser editor for [Katnip](https://github.com/Katnip-org/Katnip). Write `.knip` files in
a Monaco editor with live diagnostics, compile with `@katnip-org/compiler`, and run the result on
a Scratch stage in the page using TurboWarp's scaffolding. Projects autosave in the browser and
can be imported and exported.

Built with Svelte and Vite, and deployed with Cloudflare Wrangler.

See [CONTRIBUTING.md](CONTRIBUTING.md) to run it locally.
